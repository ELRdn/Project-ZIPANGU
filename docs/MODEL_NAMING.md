# Model naming

Pattern: `ZIPANGU-{Class}-{Generation}-{Size}`

| Code | Reading | Meaning |
|---|---|---|
| K | Kei / 軽 | Lightweight |
| C | Chū / 中 | Middleweight |
| Z | Zyū / 重 | Heavyweight |

Generation uses iroha order:

`I → RO → HA → NI → HO → HE → TO → CHI → RI → NU → ...`

Generation changes for a substantial ZIPANGU recipe change, not a simple bugfix.

First model: **ZIPANGU-C-I-9B**.

The upstream base version belongs in model metadata, not in the ZIPANGU brand name.
